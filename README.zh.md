## 缘起

大项目都有小起点。Vue 的第一行代码写在一间公寓里；Linux 诞生于一封关于"只是一个爱好"的邮件。聚光灯是后到的，故事先发生在角落。

我们生活在一个被"明星项目"定义的时代。榜单、趋势、大厂背书，决定了什么样的代码值得被看见。但历史反复证明：改变世界的项目，往往从无人问津的仓库开始。OpenFork 存在的理由，就是让这些仓库不再被埋没。

## 理念

> 伟大的项目并非生而伟大。它们始于一次 commit、一个 issue、一个深夜的实验。

OpenFork 的使命有两半，彼此咬合。第一半，是在聚光灯之外寻找被低估的小项目，用搜索、推荐与整理，把光打向它们。第二半，是降低参与的起点——一个 fork、一个 star、一条 issue，都算数。大项目不是等来的，是被一个个普通人"抬"起来的。抬的人多了，小项目就成了大项目。

---

## 三条信条

> **一** · 看见小事，是看见未来的方式。

> **二** · 一次 fork 就是一次投票，一次贡献就是一次孵化。

> **三** · 开源的伟大，不在于它属于巨头，而在于它属于每个人。

## 原则

| 原则 | 含义 |
| --- | --- |
| 以小事为锚 | 不追逐热度，只追逐潜力。品味的养成，始于看见别人跳过的东西。 |
| 行动先于掌声 | 一次真实的贡献，胜过一百次转发。 |
| 去中心化 | 不依附大厂与单一资本。伟大，能在聚光灯之外存活。 |
| 长期主义 | 我们照料花园，但不提前收割。 |
| 平民可及 | 低门槛、可参与、可复制。开源是每个人的权利，不是少数人的特权。 |

## 如何参与

1. **fork 一个冷门仓库**——先让它进入你的视野。
2. **star 你在意的项目**——让算法和人都看到它。
3. **回答一条 issue、修一个 bug、补一段文档**——任何贡献都算数。
4. **分享你发现的宝藏仓库**——推荐是最好的聚光。

---

## 愿景

> 当小项目不再需要"熬成"大项目才被看见，
> 当每个人都能轻松参与、平等共创，
> 开源的平民时代才真正到来。

OpenFork 不发明潮流，只负责在潮流到来之前，先看见那些值得被看见的仓库。
